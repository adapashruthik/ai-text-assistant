AI Text Assistant

A beginner-friendly local AI chatbot built using Python, Ollama, and Llama 3.2 (3B).

Features

Interactive AI question-and-answer assistant

Custom system prompts

Conversation memory during a session

/help and /clear commands

Basic error handling

Local inference without a paid AI API

Tech Stack

Python

Ollama

Llama 3.2 (3B)

Architecture

User → Python application → Ollama → Llama 3.2 → AI response

Run Locally

Install Python and Ollama.

Download the model: ollama pull llama3.2:3b

Install dependencies: pip install -r requirements.txt

Run the application: python app.py

Learning Outcomes

Practiced local LLM integration, prompt engineering, conversation history, command handling, and error handling.
